# multi-level-csv

TradingView chart exports for Icarus / Opus / Astra.

- Older zips: candles, tick/range, profile overlays, indexes.
- New (2026-09-22): six batches `Csv first 60` … `Last 57 half` = 177 equity candidate CSVs.
- Integration: `CANDIDATE_COG_GROK.md` (Grok xAI). Do not ingest BATS names as NQ history.
